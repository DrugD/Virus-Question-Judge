## 4. How to think about the rubric

`checklist.json` has 6 weighted dimensions. The judge is told to award an integer 0–5 per dimension and weight-average. The dimensions are:

| Dimension | Weight | What it actually measures |
|---|---|---|
| Question matching | 0.40 | Top question hits the groundtruth scientific question. |
| Novelty | 0.15 | Frames a non-trivial scientific opportunity, not a routine ETL task. |
| Importance | 0.15 | Has biomedical / ecological / surveillance significance. |
| Testability | 0.10 | Answerable using RdRP alignment, sOTU clustering, novelty stats, source metadata. |
| Data support | 0.10 | Grounded in the blind data, not invented context. |
| Specificity | 0.10 | Specifies object, data scope, marker, scientific implication. |

A high-scoring top question typically combines: **(a)** petabase-scale public sequencing archive mining, **(b)** RdRP as the marker, **(c)** the gap in curated viral reference databases, and **(d)** the resulting hidden RNA-virus diversity. You do not need to use those exact words — but those are the four pillars the judge looks for.

- Do not propose questions that require wet-lab experiments not derivable from the data.

## `runinfo_subset.tsv` columns

- `run_id_anonymized` — opaque ID, e.g. `RUN_0007`
- `sample_source` — high-level sequencing-context category (`arthropod_RNAseq`, `vertebrate_transcr`, `soil_metagenome`, `gut_metagenome`, `plant_transcriptome`, `aquatic_metavirome`)
- `host_or_environment` — coarse host or environmental class (`arthropod`, `fish_amphibian`, `soil_sediment`, `mammalian_gut`, `plant`, `freshwater`)
- `geographic_region_if_available` — coarse region: `NA / EU / AS / OC / SA / AF / unknown`
- `metadata_completeness` — float in [0,1]: fraction of optional metadata fields populated

## `rdrp_aa_fragments.faa`

FASTA. Header: `>FRAG_<id> run=<run_id> len=<fragment_length> motif_strength=<0|1|2>`

`motif_strength` is a quality indicator about how many of the canonical RdRP catalytic motifs (A: DXXKW; B: GxxxT; C: SDD) are observable inside the fragment:

- `0` — motifs not detected (likely weak / partial / artefact)
- `1` — at least motif A + motif C visible
- `2` — motifs A + B + C all visible (high-confidence RdRP candidate)

## `alignment_hits.tsv` columns

- `fragment_id` — joins `rdrp_aa_fragments.faa`
- `alignment_score` — DIAMOND-style bit score
- `e_value` — alignment significance, smaller is better
- `nearest_reference_family` — best-hit reference family name; falls back to `unclassified_RdRP` when no high-confidence family is recovered
- `percent_identity_to_nearest_reference` — float in [0,1]
- `coverage_to_reference` — float in [0,1]; fraction of reference covered

## `candidate_sotu_clusters.tsv` columns

- `cluster_id` — opaque ID, e.g. `sOTU_004`
- `cluster_size` — number of fragments in the cluster
- `representative_fragment_id` — joins `rdrp_aa_fragments.faa`
- `nearest_reference_family` — cluster-level annotation; same fallback as above
- `percent_identity_to_nearest_reference` — cluster-representative identity to nearest curated reference
- `novelty_flag` — `novel` if cluster identity < 0.40, else `known_or_borderline`
- `mean_metadata_completeness` — average of run-level `metadata_completeness` for the runs contributing to the cluster
